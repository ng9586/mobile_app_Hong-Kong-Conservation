## Using GPTNetwork

To use the AI chatbot functionality in this project, you need to provide an API key for the ChatAnywhere service. Follow these steps:

1. Open the `GPTNetwork.swift` file in your project.
2. Locate the `APIKey` property at the top of the `GPTNetwork` class.
3. Replace `"your-api-key"` with your actual API key.

### Obtaining an API Key

To get an API key for the ChatAnywhere service:

1. Visit the [ChatAnywhere GitHub repository](https://github.com/chatanywhere/GPT_API_free).
2. Follow the instructions in the README to obtain a free API key.
3. Once you have your API key, use it in the `GPTNetwork` class as shown above.
