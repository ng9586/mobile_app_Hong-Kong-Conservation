## Using GPTNetwork

To use the AI chatbot functionality in this project, you need to provide an API key for the ChatAnywhere service. Follow these steps:

1. Open the `GPTNetwork.swift` file in your project.
2. Locate the `APIKey` property at the top of the `GPTNetwork` class.
3. Replace `"your-api-key"` with your actual API key.
